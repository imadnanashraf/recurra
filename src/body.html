Instant admin actions (GitHub key)

  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it Recurra admin. Repository access: Only select repositories → recurra.
  3. Repository permissions → Actions: Read and write. Nothing else.
  4. Generate, copy it, paste it here and Save.
